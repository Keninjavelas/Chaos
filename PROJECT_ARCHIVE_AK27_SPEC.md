# PROJECT ARCHIVE AK-27

## Complete Design \& Technical Specification

# 1\. Vision

PROJECT ARCHIVE AK-27 is not a traditional portfolio.
It is an interactive psychological archive documenting the life, work, interests, projects, research, and ambitions of Aryan Kapoor.

The website should initially mislead visitors into believing they have discovered a nostalgic and harmless internet experience before gradually revealing a deteriorating archive that appears self-aware.

The site must balance:

* Portfolio
* Interactive art
* Psychological thriller
* Engineering showcase

The goal is to leave visitors thinking:

> "I came to view a portfolio.
> I left feeling like I explored someone's mind."

\---

# 2\. Core Philosophy

The website is never a haunted house.

The website is never a horror game.

The website is an archive.

The archive:

* Remembers
* Observes
* Records
* Deteriorates

The horror comes from inevitability, memory corruption, observation, contradiction, and persistence.

\---

# 3\. Complete User Journey

## Stage 1: False Comfort

User arrives.

A cheerful retro desktop appears.

Features:

* Windows XP inspired environment
* Bright colors
* Cat memes
* Retro internet humor
* Fake loading screen
* Desktop icons
* Popups

As loading progresses:

* More memes appear
* More windows appear
* More desktop clutter appears

Top-right:

SKIP INTRO

\---

## Stage 2: Blackout

Progress reaches 100%.

Instant cut.

No fade.

Entire screen becomes black.

The screen behaves like a monitor.

A subtle front-facing silhouette reflection is visible.

The silhouette is vague and unrecognizable.

\---

## Stage 3: Philosophical Quote

White text appears.

Random quote selected from:

* Nietzsche
* Camus
* Kierkegaard
* Schopenhauer
* Cioran

Displayed for approximately 7 seconds.

Music is completely silent.

Quote fades.

\---

## Stage 4: Archive Entry

Homepage loads.

Ambient archive atmosphere begins.

The investigation starts.

* Panic movement
* Visits
